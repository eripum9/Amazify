# Amazify

<img src="assets/logo.png" alt="Amazify logo" width="96">

## Under redevelopment

Amazify is being rebuilt as a full custom, cross-platform client for Amazon Music.

The previous Windows-only runtime injection prototype has been retired. The new project will focus on an Amazify-owned interface, a portable desktop architecture, and a safer plugin platform for themes, player extensions, integrations, and custom experiences.

The initial target platforms are:

- Windows
- macOS
- Linux

This rewrite is in its earliest planning and prototyping stage. There is currently no supported release or installer to download.

## Direction

The new Amazify is intended to provide:

- A complete custom desktop interface
- Cross-platform playback and account sessions
- A documented, permission-based plugin SDK
- An open-source plugin marketplace
- First-party plugins that are reviewed and thoroughly tested
- Clear warnings and permission details for third-party plugins

Technical scope and platform support will be finalized after playback, authentication, and DRM feasibility testing across all three desktop operating systems.
