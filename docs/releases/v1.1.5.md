Amazify v1.1.5 fixes connection failures that could prevent the companion from attaching to Amazon Music.

## Fixed

- Fixed attachment on Windows systems where the TCP table does not expose a usable listening-process entry for Amazon Music's debugging endpoint.
- When listener metadata is incomplete, verify the Amazon Music process using the exact server-side connection of a short-lived loopback probe.
- Allow a bounded wait for Windows to expose the probe's connection row, avoiding intermittent attachment failures.
- Retry transient listener-discovery failures within the existing startup deadline rather than abandoning startup immediately.
- Updated vulnerable build dependencies, including Pillow, certifi, filelock, and setuptools.

## Verification

- Process-ownership verification remains required. Untrusted processes, non-loopback endpoints, and unverified connections are rejected.
- Added regression tests for startup timing, incomplete socket metadata, exact connection matching, conflicting owners, and probe cleanup.

## Installation

Download **AmazifySetup.exe** below, or check for updates in Amazify. The installer is unsigned, so Windows SmartScreen may display a warning.

Existing plugins and settings are retained. No plugin updates are required for this fix.
