Amazify v1.1.4 fixes Signal Studio carousel navigation, improves fullscreen restoration and rich-lyrics presentation, and refreshes the dependency environment.

## Fixed

- Bound taskbar grouping to the Amazon Music process launched by Amazify, preventing unrelated browser windows with "Amazon Music" in their title from joining its taskbar group.
- Fixed Signal Studio's small next/previous arrows across recommendation and artist carousels by preserving Amazon's native scroll containers.
- Improved window restoration after leaving fullscreen, including the playback bar's placement.
- Added a working True Big Mode setting to control automatic fullscreen. It defaults to off.
- Improved rich-lyrics parsing for nested/background vocals and providers that return only usable portions of a payload.
- Improved provider lookup behavior when a provider requires authentication, with native Amazon lyrics remaining the fallback.

## Lyrics and Fullscreen

- Preserved presentation typography during karaoke highlighting.
- Smoothed word/syllable motion and playback timing between Amazon's position updates.
- Greyed out upcoming lyrics in True Big Mode and added a manual retry action for rich-lyrics lookups.
- Hardened fullscreen ownership, asynchronous entry/exit, and cleanup so plugins do not accidentally exit unrelated fullscreen sessions.
- Updated the fullscreen API documentation for plugin developers.

## Plugin Updates

- **Signal Studio 0.2.2**: carousel navigation fix and fullscreen/layout improvements.
- **True Big Mode 0.2.3**: automatic-fullscreen controls and reliable restoration.
- **Karaoke Lyrics 0.2.5**: typography, timing, motion, upcoming-line styling, and retry improvements.

## Dependencies and Verification

- Refreshed runtime, development, and build dependency locks, including urllib3 2.8.0 to address three dependency vulnerabilities.
- Updated CodeQL and added regression checks that keep dependency inputs and generated locks consistent.
- Dependency audits report no known vulnerabilities in the runtime, development, or build locks.
- Python and JavaScript regression tests pass; carousel navigation was verified with real next/previous clicks in Amazon Music.

## Installation

Download **AmazifySetup.exe** below, or check for updates in Amazify. The installer is unsigned, so Windows SmartScreen may display a warning.

Rich lyrics depend on third-party provider availability. When unavailable, Amazon's native lyrics remain visible.
